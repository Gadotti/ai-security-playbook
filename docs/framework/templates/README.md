# Templates

Fillable Markdown templates for the recurring reviews the [framework](../README.md) implies.

- [risk-review-template.md](risk-review-template.md) — before shipping a new LLM-backed feature or agent.
- [tool-onboarding-checklist.md](tool-onboarding-checklist.md) — before connecting a new agent skill, MCP server, or tool integration.
- [incident-log-template.md](incident-log-template.md) — for logging an AI security incident or significant near-miss.

Copy the one you need into your own tracker (an issue, a doc, a wiki page) rather than editing it in place here.
