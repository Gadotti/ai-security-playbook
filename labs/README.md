# Labs

Reproducible, runnable security labs. Each lab has its own `README.md` with setup, usage, and expected output — treat prose-only labs as incomplete.

- [skillspector-scan/](skillspector-scan/) — scanning agent skills/tools for risk with NVIDIA SkillSpector
- [ai-jail/](ai-jail/) — sandboxing patterns for agent execution
- [prompt-anonymizer/](prompt-anonymizer/) — spike/PoC for intercepting and masking sensitive data in prompts
- [injection-tests/](injection-tests/) — educational prompt injection test cases

Lab code defaults to Python. Content for this section is planned for Phase 2.
