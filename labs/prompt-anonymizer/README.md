# Lab: Prompt anonymizer (spike/PoC)

**Status: spike/PoC.** This idea (a proxy/interception layer that masks sensitive data — PII, secrets, customer data — before it reaches the model, with response re-hydration) has not been validated yet.

Planned for Phase 2:
- Survey of existing approaches/tools, checked for whether they're still active and maintained.
- Comparison of approaches (regex/NER-based masking, structured tokenization + reversible mapping, etc.).
- A minimal prototype, clearly labeled as a PoC, not production-ready.
