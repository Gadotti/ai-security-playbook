# System prompts

Versioned base system prompts for LLM agents/assistants, provider-agnostic (tested against Claude, OpenAI, and local models via Ollama where practical).

Each prompt variant should include:
- The prompt itself.
- A short rationale for each non-obvious instruction (why it's there, what it defends against).
- Known limitations / bypasses found during testing.

Content for this section is planned for Phase 2.
